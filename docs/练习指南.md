# 练习指南：怎么练最高效

> 这份指南按「时间花在哪最值」来写，不是功能说明书。
> 功能怎么用，界面上都有提示；这里说的是**怎么用才有效**。

---

## 一、先记住一条底层规则

**这个平台的设计前提是：4h 决定方向，1h 找入场，15m 定细节。**

| 周期 | 角色 | 该看什么 | 不该用它做什么 |
|---|---|---|---|
| **4h 趋势** | 定方向 | 均线排列、价格相对位置、通道 | ❌ 不该用来找具体入场点 |
| **1h 入场** | 找机会 | 回调结构、企稳信号、量能 | ❌ 不该用来判断大方向 |
| **15m 精入场** | 定细节 | 小时内部的进场位置 | ❌ **绝对不该用来定方向** |

**最常见的失败模式**：在 15m 图上看到形态就动手 —— 15m 的形态在 4h 上经常是噪音。
练之前先在 4h 上确认方向，否则这一单从根上就错了。

---

## 二、开练前的 3 分钟设置

### 1. 选起点（别随便选）

点「⏱ 起点」，系统给的可调范围是 `2026-09-28 ~ 2026-10-25`（随数据量变）。
**挑一个「4h 趋势刚好明确、但后面还有足够波动」的时间点**。

> 为什么有范围限制：起点前要留 120 根 4h 的趋势上下文（不然你看不出趋势），
> 起点后要留 60 根 1h 的未来（不然没东西可回放）。这个约束是产品要求，不是 bug。

### 2. 配指标（4h 和 1h 是**两套独立配置**）

| 档位 | 建议配置 | 理由 |
|---|---|---|
| **4h 趋势** | `MA` + `BOLL` | 均线看排列方向，布林看通道位置 |
| **1h 入场** | `MA` + `VOL` | 均线定结构，量能确认有效性 |

> 打开指标面板时，它会**自动切到你当前图表所在的档位**（面板顶部写着「当前图表：1h」）。
> 改完记得确认一下当前选中的是哪个 tab —— 4h 和 1h 的配置是分开的，改错档位等于没改。
>
> 副图最多 4 个。建议：**4h 档留 1~2 个**（副图挤主图），**1h 档可以用满**。

### 3. 心里定好「这笔交易的前提」

开仓前先在纸上/脑子里回答：**我凭什么觉得会涨/跌？**
写进「设置」和「检查表」里 —— 那 5 套设置（趋势回调入场 / 突破回踩 / 假突破反转 / 区间边缘高抛低吸 / 趋势延续旗形）就是 5 种不同的前提。
**前提说不清的单子，练了也白练**（复盘时你会发现「当时到底为什么开？」）。

## 三、练习节奏：单步 vs 播放，别混用

| 方式 | 什么时候用 | 效果 |
|---|---|---|
| **单步 ▶**（步长 = 当前图表周期） | **做决策时** | 一根一根看，能真正思考 |
| **播放 ▶** | **建立直觉 / 摸节奏** | 快，但错过就没了 |
| **4h ⏩ / 退4h** | 4h 档快进快退 | 效率工具 |
| **后退 ◀** | **看错了要回看** | 这是设计，不是 bug |

### 最高效的组合（实测下来）

```
1. 4h 档 → 「4h ⏩」快进到当前时刻 → 用 30 秒判断方向（多/空/观望）
2. 1h 档 → 回到起点 → 「单步 ▶」逐根推进（这是主要耗时区）
3. 1h 出现信号 → 切 15m 档 → 「单步 ▶」看这一小时内部 → 找精确进场位
4. 开仓（止损必须有结构依据，不能是"随便放个整数"）
5. 继续推进到出场 → 强制复盘 → **认真写**
```

**关键点：第 2 步的"逐根推进"才是练习本体。**
播放只是让你看个热闹 —— 决策时间被压缩掉，就没练到东西。

## 四、三个提速技巧

### 1. 用画线工具做标注（v6.3 新增）

「✏ 画线」→ 趋势线 / 水平线 / 价格线。

- 进场的**结构位**画水平线 → 出场时回看，验证当初画的线准不准
- **趋势线**连两个关键低点 → 破位了就是信号
- 画线**切周期保留、换标的自动清**（不会串味）

> 用法：点工具 → 图上出现带控制点的线 → **拖动端点**调整 → 点选后按 `Delete` 删除。

### 2. 遇到不确定就后退（回看模式）

如果你发现"刚才那根我判断错了"，直接点「◀ 后退」——
**回看模式不能开仓是设计**（防止你在回看历史时冲动下单），
但**回看本身完全自由**，想看多久看多久。

### 3. 关注「纪律指标」而不是「胜率」

统计看板里比胜率更有价值的是：
- **守规则率** —— 你有多少单是按计划做的（这个才是刻意练习的核心指标）
- **单笔期望** —— 平均每单赚多少 R
- **最大回撤** —— 连续亏损时你会不会崩

> 胜率低但守规则率高 = 正在进步（方法对，样本少）。
> 胜率高但守规则率低 = 危险（运气好，或在赌）。
>
> 胜率 PK 也是同理：**比纪律不比运气**。

## 五、强制复盘：不要跳过

平仓后强制弹复盘，有四个出口（✕ / ESC / 点遮罩 / **跳过**）。

**跳过是被允许的**（不阻塞继续练），但**跳过会记为「未复盘」，并计入纪律指标**。

复盘里三个问题（对应产品的三个字段）：
1. **followedPlan** —— 有没有按计划做？（最核心）
2. **emotion** —— 当时什么情绪？（FOMO / 恐惧 / 急躁 / 平静）
3. **mistakeTag** —— 错在哪？（追高 / 没止损 / 提前平 / 逆势 / 无信号开仓）

> **每笔都写**，三行就够。跳过的那几笔，事后在「待补复盘」里补上。
> 复盘是这个平台唯一会真正改变你行为的东西 —— 不写等于没练。

## 六、别这么练（反模式清单）

| ❌ 别做 | 为什么 |
|---|---|
| 打开就播放，看完爽一下 | 决策被压缩，等于没练 |
| 开了仓就跳过复盘 | 纪律指标失真，复盘才是本体 |
| 在 15m 上定方向 | 15m 的形态在 4h 上常是噪音 |
| 止损随手放个整数 | 没有结构依据的止损 = 没有风控 |
| 一次练 3 小时不停 | 刻意练习靠强度不靠时长，20 分钟高质量 > 2 小时疲劳 |
| 只做自己看懂的行情 | 要练的是**流程**，不是判断 —— 所以才用「设置 + 检查表」强制 |

## 七、一套具体的 25 分钟流程（可直接照做）

| 时段 | 动作 | 要点 |
|---|---|---|
| 0-3 min | 选标的 + 设起点 + 配 4h/1h 指标 | 4h 用 MA+BOLL，1h 用 MA+VOL |
| 3-6 min | 4h 档「4h ⏩」到当前时刻 | 只判断方向：多 / 空 / 观望 |
| 6-18 min | 1h 档回起点，**逐根推进** | 看到符合某个「设置」+ 检查表全勾 → 准备开 |
| 18-21 min | 切 15m 档，单步看这一小时内部 | 找精确进场位（别在这里改方向） |
| 21-22 min | 开仓 | 止损必须有结构依据 |
| 22-25 min | 推进到出场 + 复盘 | 三行写完，别跳过 |

**一天一到两次，20-25 分钟一次。**
刻意练习拼的是**次数 × 决策质量**，不是时长。

## 八、常用命令（自测用）

```bash
# 起服务（前端 + API 一个进程）
cd server && node src/index.js      # → http://127.0.0.1:8787

# 跑全量验证（292 项）
npm run verify

# 清理验证产生的测试数据（保留你自己的账号）
npm run cleanup:testdata            # 预览
npm run cleanup:testdata -- --yes   # 真删

# 补数据
npm run db:mat15m                                  # 源表 15m 物化（60 秒）
npm run deep:fill -- --symbols BTCUSDT --market spot --interval 15m --since 2017-08-17
npm run deep:fill:all                              # 其余标的批量深回填（慢，数小时）
```
